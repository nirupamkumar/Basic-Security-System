# Basic Security System

A simple C++ console application created in February 2023 as a personal programming experiment.

> **Status: Archived — No Longer Maintained**

## Overview

This project was created to practice basic C++ programming concepts through a console-based user account system.

## Features

- User registration
- User login
- Password changes

## Technology

- C++
- Visual Studio
- Console application

## Running the Project

1. Clone the repository.
2. Open `ConsoleSecuritySystem.sln` in Visual Studio.
3. Build and run the application.

## Security Notice

This is an educational experiment, not a production-ready authentication system. Its security properties have not been audited, and it should not be used to protect real accounts or sensitive information.

## Project Status

Development ended in February 2023. The repository is archived for personal learning history and reference.
